# E-Tut Studo-Einladung

Zwischenseite für das Erstsemestrigentutorium MB & WIMB an der TU Wien.

- Verteilt die Studo-Einladungslinks der beiden Tutor:innen **streng abwechselnd** (gemeinsamer Zähler über abacus.jasoncameron.dev, Notfall: Zufall).
- Kopiert den Link per Button in die Zwischenablage und öffnet danach den Store.
- Wer die Seite erneut öffnet, bekommt wieder denselben Link.

Extras:
- `?stats=1` zeigt, wie viele Einladungen schon verteilt wurden (zählt nicht mit).
- `?t=1` bzw. `?t=2` erzwingt einen bestimmten Link.
