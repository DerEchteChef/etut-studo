# E-Tut Studo-Einladung

Zwischenseite für das Erstsemestrigentutorium MB & WIMB an der TU Wien.

- Verteilt die Studo-Einladungslinks der beiden Tutor:innen abwechselnd.
- Kopiert den Link per Button in die Zwischenablage und öffnet danach den Store.
- Wer die Seite erneut öffnet, bekommt wieder denselben Link.
- Schritt-für-Schritt-Anleitung für Studo.
